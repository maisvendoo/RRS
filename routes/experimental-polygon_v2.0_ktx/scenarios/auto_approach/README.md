## Демонстрация автоматического пропуска поездов по станции

Устанавливаются два поезда, движущиеся в автоматическом режиме. Каждый из поездов расположен за 50 метров до второго участка приближения к станции B. С помощью функции setAutoApproachTrigger() организуется автоматический пропуск поездов по станции B.
