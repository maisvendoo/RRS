## Бесконечная поездка по испытательному кольцу

Поезд расположен на пути 2Б станции А. Через минуту после начала игры ему строится поездной маршрут на исптытательное кольцо. При движении по кольцу выполняется автоматическое управление сигнализацией на кольце, для обеспечения сколь угодно долгого движения поезда по кольцу
