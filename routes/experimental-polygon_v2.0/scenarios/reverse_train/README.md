## Разворот поезда с использованием временных триггеров

Демонстрируется разворот поезда (изменение его направления на противоположное) с помощью временного триггера. Состав из локомотива ВЛ60пк-1543 и 17 пассажирских вагонов дважды разворачивается с интервалом в 10 секунд, возвращаясь в исходное направление.
