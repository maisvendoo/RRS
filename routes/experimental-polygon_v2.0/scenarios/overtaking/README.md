## Организация обгона с применением позиционных триггеров

Поезд 1 принимается на 4 путь станции B. После заезда поезда 1 на 4 путь строится маршрут пропуска для поезда 3, следующего за поездом 1. После пропуска поезда 3 по главным путям станции B, выполняется построение маршрута отправления для поезда 1.
