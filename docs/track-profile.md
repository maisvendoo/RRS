# Профиль неровностей пути (ТЗ «Неровности пути»)

Система связывает геометрию пути с вертикальной динамикой подвижного состава:
рельсовый профиль → колёсная пара → первая ступень подвешивания → тележка →
вторая ступень → кузов → игрок/камера/звук (потребители ускорений).

Неровность — свойство пути, а не вагона: профиль детерминирован, задаётся
в метрах вдоль координаты пути и одинаков для всех поездов и при повторных
проездах. Скорость влияет только на динамический отклик.

## Модуль `simulator/track-profile`

| Файл | Назначение |
|------|-----------|
| `track-irregularity.h/cpp` | Типы неровностей и их формы (стык, шов, просадка, выбоина, выпучивание, волнообразный износ) |
| `track-condition.h/cpp` | Состояние пути (excellent…critical), масштабирует амплитуды |
| `rail-profile.h/cpp` | Профиль рельса: явные неровности + автогенерация стыков/швов + детерминированный шум; чтение `track-profile.conf` |

Формы непрерывны по первой производной (C1) — рывок конечен. Стык — резкая
полуволна косинуса с износом; шов — плавная горка sin², амплитуда падает с
качеством сварки; просадка — трапеция со smoothstep-склонами.

Шум — детерминированный value-noise по целочисленной решётке координаты
(хэш MururHash3-финалайзер), октавы 3.1/9.7/34 м. Чётные октавы общие для
рельсов (просадка), нечётные свои на рельс (перекос/крутка).

## Интеграция

- `Trajectory` (топология) строит профиль при загрузке (конфиг маршрута
  кэшируется на все траектории, seed смешивается с именем пути);
  запрос: `Trajectory::getRailHeight(traj_coord, side)`.
- `VehicleController::getRailHeightAt(path_coord, side)` — для осей ПЕ.
- `Vehicle` — источник привязывается один раз из `Train::slotStep`
  (лямбда на контроллер ПЕ); шаг — из `Vehicle::integrationProcess`
  (невиртуальный, работает при переопределённом `process()`).
- Динамическая нагрузка осей модулирует `axis_load[i]` → влияет на
  реализуемое сцепление колеса с рельсом (разгрузка при колебаниях).
- Датчики для потребителя: `getBodyAcceleration()`, `getBodyJerk()`,
  `getAxleLoadFactor(i)`, `isAxleUnloaded(i)`, метрики комфорта:
  RMS, max, jerk, счётчик ударов, индекс плавности.

## Модель вертикальной динамики (`vehicle-dynamics.h/cpp`)

Многотельная модель в отклонениях от статического равновесия (гравитация
и статические выборки сокращаются):

- колёсные пары: подпрыгивание + крен (неподрессоренные массы);
- контакт колеса с рельсом — односторонняя пружина (линейная
  аппроксимация Герца, `ContactStiffness` по умолчанию 1 ГН/м на пару);
  потеря контакта детектируется при силе < 0;
- первая ступень (колесо↔тележка) и вторая (тележка↔кузов): пружина +
  демпфер + упоры за пределами хода (жёсткость ×8);
- кузов: подпрыгивание, тангаж, крен; подрессоренная масса пересчитывается
  под текущую загрузку ПЕ;
- интегрирование — полунеявный Эйлер с подшагом ≤1 мс (жёсткий контакт);
- вход — высота рельса под каждым колесом по координате пути;
  продвижение координат внутри подшагов аналитическое по скорости.

Ограничение стадии: контакт Герца линеен; нелинейная модель
(F ~ δ^1.5, пятно контакта) — в ТЗ поперечной динамики.

## Конфигурация

### Маршрут: `track-profile.conf` (XML, каталог маршрута)

```xml
<Config>
    <TrackProfile>
        <Enabled>true</Enabled>
        <Seed>18273</Seed>
        <Condition>normal</Condition>
        <JointSpacing>25</JointSpacing>       <!-- 0 - без изолированных стыков -->
        <JointAmplitude>0.004</JointAmplitude>
        <JointLength>0.12</JointLength>
        <WeldSpacing>12.5</WeldSpacing>
        <WeldAmplitude>0.0015</WeldAmplitude>
        <WeldLength>0.45</WeldLength>
        <WeldQuality>0.75</WeldQuality>
        <NoiseEnabled>true</NoiseEnabled>
        <NoiseAmplitude>0.0012</NoiseAmplitude>
        <TwistAmplitude>0.0008</TwistAmplitude>
    </TrackProfile>
    <!-- Явная неровность на конкретном пути -->
    <Irregularity>
        <Trajectory>route1_0001_1</Trajectory>
        <Type>depression</Type>   <!-- joint|weld|depression|dip|bulge|wave -->
        <Coord>250.0</Coord>
        <Amplitude>0.035</Amplitude>
        <Length>18.0</Length>
        <EntryLength>4.0</EntryLength>
        <ExitLength>4.0</ExitLength>
        <Side>both</Side>         <!-- left|right|both -->
    </Irregularity>
    <!-- Состояние отдельного пути -->
    <TrajectoryCondition>
        <Trajectory>branch1_0002_1_12_22</Trajectory>
        <Level>poor</Level>
    </TrajectoryCondition>
</Config>
```

Отсутствие файла — не ошибка: работают умолчания (стыки 25 м, швы 12.5 м,
шум включён, состояние normal).

```xml
<Suspension>
    <Enabled>true</Enabled>
    <PrimaryStiffness>1200000</PrimaryStiffness>   <!-- Н/м на ось -->
    <PrimaryDamping>25000</PrimaryDamping>         <!-- Н*с/м на ось -->
    <PrimaryStroke>0.06</PrimaryStroke>            <!-- м -->
    <SecondaryStiffness>450000</SecondaryStiffness><!-- Н/м на тележку -->
    <SecondaryDamping>18000</SecondaryDamping>
    <SecondaryStroke>0.09</SecondaryStroke>
    <WheelsetMass>1400</WheelsetMass>              <!-- кг -->
    <BogieMass>2200</BogieMass>
    <ContactStiffness>1000000000</ContactStiffness><!-- Н/м на пару -->
    <BogieOffset>4.86</BogieOffset>                <!-- м от центра ПЕ -->
    <WheelsetSpacing>1.85</WheelsetSpacing>        <!-- м между осями -->
    <NumBogies>2</NumBogies>

    <RollRadius>1.15</RollRadius>
    <Substep>0.001</Substep>                       <!-- с -->

```

## Верификация

`_verify/verify_track_profile.py` (в каталоге проекта вне репозитория RRS) —
Python-зеркало форм, шума и интегратора. Проверено: формы C1-непрерывны и
имеют заявленную амплитуду; шум детерминирован, различается по путям и
сторонам рельса; идеальный путь — нулевой отклик; отклик на стык растёт с
20→60→100 км/ч; грузовой и пассажирский вагоны отвечают по-разному;
просадка даёт плавный низкочастотный отклик (jerk ≈ 1.5 м/с³ против
ударного у стыка); грубый стык на 80 км/ч даёт пик нагрузки оси и полную
разгрузку колеса после пика; повторный проезд идентичен.
