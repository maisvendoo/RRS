# Поперечная динамика ПС (ТЗ «Поперечная динамика», «Динамика тележек»)

Виляние возникает из физики контакта колеса с рельсом, а не генератора
`sin(time)`: конический профиль бандажей → разница радиусов качения →
кинематика Клингеля → крип-силы Картера → подвешивание → виляние кузова.

## ТЗ «Динамика тележек» — дополнения

- **Люфты**: `PrimaryYawFreePlay` (колёсная пара в тележке) и
  `BogieYawFreePlay` (поворот тележки) — dead-zone: внутри зоны усилие
  не растёт, после выборки включается жёсткость.
- **Возвратный момент тележки** `BogieYawStiffness` к равновесию
  относительно кузова (с люфтом).
- **Угол набегания** `getWheelsetAngleOfAttack(i)`: рыскание колёсной
  пары минус касательная к пути под осью (в кривой касательная
  поворачивается на curvature·смещение оси). Геометрически оси
  симметричны ±; асимметрия набегающей оси возникает динамически через
  контакт гребня.
- **Относительный угол тележки** `getBogieRelativeYaw(k)` =
  BogieYaw − VehicleYaw; в кривой радиальная установка ≈ базе/(2R).
- **Состояния контакта** `getWheelContactState(axle, side)`:
  Rolling / Adhesion / PartialSlip / Sliding / FlangeContact /
  LossOfContact — классификация по насыщению крипа, гребню и разгрузке.
- **Износ**: `setConicity()` — износ бандажей повышает коничность
  (снижает критическую скорость); вызывается системами износа.

## Физическая модель (`simulator/vehicle/vehicle-lateral-dynamics`)

Степени свободы каждой ПЕ: колёсные пары (боковое смещение y + рыскание
ψ), тележки (y + ψ), кузов (y + ψ). Ось Y — вправо от оси пути.

- **Коничность** `conicity` (tan угла конуса, умолчание 0.05 = 1/20):
  эффективные радиусы r_L = r0 + γ·y_rel, r_R = r0 − γ·y_rel, где
  y_rel — смещение относительно оси пути (с учётом боковой неровности).
- **Крип (Картер/Калкер)** — в релаксационной форме: скорость колёсной
  пары релаксирует к скорости «без проскальзывания» экспоненциально с
  постоянной τ = m·v/f_eff. Боковой нуль-крип: ẏ = v·ψ; продольный
  (кинематика Клингеля): ψ̇ = −γ·v·y_rel/(a·r0). Насыщение коэффициента
  крипа трением: f_eff ≤ 2μQ·v/0.01 — сила контакта ограничена μQ.
  Релаксационная форма безусловно устойчива при любом шаге и воспроизводит
  переходный крип Калкера в линейном пределе.
- **Гребень**: люфт `FlangeClearance` (умолчание 23 мм), далее
  односторонняя пружина-демпфер `FlangeStiffness/Damping` (сила ≤ 400 кН).
- **Подвешивание**: I ступень (колёсная пара ↔ тележка) поперечно +
  рыскание (PrimaryYawStiffness — ключевой параметр устойчивости);
  II ступень (тележка ↔ кузов) + боковые упоры с люфтом.
- **Возбуждение**: боковые неровности плана линии — детерминированный шум
  в `track-profile` (`lateralOffset`), свои октавы (6.3/23 м),
  конфиг `LateralNoiseAmplitude`; кривизна пути из `profile_point` —
  центробежная составляющая на все массы + перенос нагрузки на колёса.
- **Y/Q и критерий Надаля**: поперечная сила колеса (крип + гребень) против
  вертикальной нагрузки (статика × нагрузка оси от вертикальной динамики ±
  перенос от кривизны). Предел: (tan β − μ)/(1 + μ·tan β), β = угол
  гребня (умолчание 65°). `isDerailmentCriterionViolated()`.
- **Критическая скорость**: `estimateCriticalSpeed()` — численный скан:
  интегрируется изолированная колёсная пара (та же модель) на сетке
  скоростей 5–90 м/с, ищется граница роста амплитуды возмущения.
  Консервативная оценка (одиночная колёсная пара); связанная система
  «две колёсные пары + рама» (режим виляния тележки) в полной модели
  может терять устойчивость раньше.

## Интеграция

- `Vehicle`: член `lateral_dynamics`; шаг — из `Vehicle::integrationProcess`
  (как вертикальная динамика); трение — текущее ψ колеса-рельс с погодным
  коэффициентом; нагрузки осей — от вертикальной динамики (связь систем).
- Источник боковых неровностей привязывается лямбдой в `Train::slotStep`
  (по контроллеру ПЕ топологии).
- Топология: `Trajectory::getLateralOffset()`,
  `VehicleController::getLateralOffsetAt()`.
- Датчики для камеры/звука/схода: `getBodyLateralPosition()`,
  `getBodyYaw()`, `getBodyLateralAcceleration()`, `getWheelLateralForce()`,
  `getWheelYQ()`, `getLateralRMS()`.

## Верификация

`_verify/verify_lateral.py`. Проверено: длина волны виляния свободной
колёсной пары 16.6 м против теории Клингеля 2π√(a·r0/γ) = 16.7 м;
самоцентрирование на 54 км/ч (новые колёса, возмущение 6 мм затухает);
критическая скорость с изношенными колёсами (γ=0.25) ниже, чем с новыми;
выше критической — рост амплитуды до гребня; сила гребня ≤ 400 кН;
предел Надаля при μ=0.25 равен 1.23; удар гребня нарушает Y/Q;
разгрузка колеса повышает Y/Q (связь с вертикальной динамикой).
