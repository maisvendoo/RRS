# Гайд: редактор маршрутов RRS (route_editor2)

Запуск: `D:\rrs\bin\route_editor2.exe` (рабочий каталог `D:\rrs\bin`).
Управление рассчитано на английскую раскладку — редактор включает её сам,
переключать вручную не нужно. Если клавиши «молчат» — кликните мышью в окно
3D-сцены (фокус ввода должен быть в сцене, а не в поле ввода GUI).

---

## 1. Камера

| Действие | Управление |
|---|---|
| Перемещение | **W A S D** (в плоскости), **Q/E** — вниз/вверх |
| Ускорение | **Shift** (быстрее), **Ctrl** (точнее) |
| Вращение камеры | зажать **ПКМ** и вести мышь |
| Панорама | зажать **СКМ** и вести мышь |
| Зум | колесо мыши |
| Фокус на выбранном | **F** |

## 2. Открытие/создание маршрута

- **File → Open route...** — выбрать каталог маршрута (например,
  `D:\rrs\routes\experimental-polygon_v2.0`).
- **File → New route...** — создать пустой каталог нового маршрута.
- **Ctrl+S** — сохранить изменения (маршрут пишется в свои конфиги:
  `route1.map`, `track-edit.conf`, `stations.conf` и т.д.).

## 3. Выделение и объекты

- **ЛКМ** — выбрать объект; **Ctrl+ЛКМ** — добавить к выделению.
- Рамка выделения — зажать ЛКМ на пустом месте и потянуть.
- **View → Model browser** — библиотека моделей: двойной клик или кнопка
  «Добавить» ставит объект в центр камеры. Список избранного — звёздочка.
- **View → route1.map** — таблица всех расставленных объектов.
- Выбранный объект двигается **гизмо**:
  - **G** — перемещение (стрелки), **R** — вращение, **T** — масштаб;
  - **X** — временно скрыть выбранное, **H** — скрыть (скрывается из
    выборки; вернуть — окно Layers/визимость);
  - **Delete** — удалить; **Ctrl+Z / Ctrl+Y** — отмена/повтор;
  - **Ctrl+C / Ctrl+V** — копирование/вставка объектов.

## 4. Пути (траектории) — клавиша P

- **P** — режим «Пути»: **ЛКМ** по линии пути выбирает траекторию
  (подсветится циановым). Повторная **P** — выход из режима.
- Окно **«Путь»** (открывается при выборе траектории) — профиль верхнего
  строения: рельсы (Р50/Р65/Р75), шпалы, щебень, уклон в ‰, предел
  скорости; кнопка **«Сгенерировать путь»** строит рельсы/шпалы/балласт
  по всей длине.
- **N** — инструмент «Сплайн»: построить НОВЫЙ путь — клики ставят
  контрольные точки, Enter/двойной клик завершает, путь сохраняется
  как новая траектория.
- Окно **Topology** (View → Topology) — таблица всех траекторий:
  длина/уклон/предел/стрелки; кнопка Go — телепорт камеры к траектории.
  Стрелки (соединения траекторий) редактируются в этом окне.

## 5. Параметрическая стройка растягиванием (главное)

Секция **«Стройка растягиванием»** в окне «Путь»:

1. Клавишей **P** выберите траекторию, вдоль которой строим.
2. В окне «Путь» раскройте «Стройка растягиванием» и выберите режим:
   - **Опоры КС** (интервал опор, м);
   - **Платформа** (ширина/высота/сторона);
   - **Насыпь** (высота/берма);
   - **Выемка** (глубина/ширина);
   - **Кювет** (сторона/ширина/глубина).
3. Зажмите **ЛКМ** на пути и тяните вдоль — рисуется оранжевая полоса
   (живое превью строящегося участка).
4. Отпустите ЛКМ — объект построен в этом диапазоне; параметры и геометрия
   сохраняются в `track-edit.conf` (объект остаётся параметрическим,
   Ctrl+S пишет всё на диск).

Также в окне «Путь» есть «Генерация» — те же генераторы кнопками на всю
длину (опоры КС, платформа, км-столбики, деревья вдоль, переезд), и секция
разложения выбранной модели вдоль пути (заборы/ограждения по интервалу).

## 6. Проверка маршрута

- **View → Validator** — анализ: разрывы путей, пересечения, слишком
  малые радиусы, незадействованные объекты. Клик по проблеме — камера
  летит к месту.
- Окно **Commands** — история команд (undo-стек).
- **View → Key bindings** — переназначение всех горячих клавиш.

## 7. Импорт реальных путей из OpenStreetMap

Консольная утилита `D:\rrs\bin\osm-import.exe`:

```
osm-import.exe --file D:\downloads\map.osm --out D:\rrs\routes\osm_msk --service --name "Москва"
osm-import.exe --bbox 55.72,37.55,55.80,37.75 --out D:\rrs\routes\osm_msk --service
```

- `--file` — локальный `.osm` XML (надёжный способ: скачайте область
  с openstreetmap.org кнопкой «Экспорт»; онлайн-режим `--bbox` зависит
  от пропускной способности канала до Overpass).
- `--service` — включать станционные/подъездные пути;
- `--simplify М` — упрощение полилиний (0.5 м по умолчанию);
- `--prefix` — префикс имён траекторий (osm).

Результат: маршрут с траекториями по реальной геометрии (X=восток,
Y=север, Z=вверх; центр области = (0,0); гео-привязка для солнца пишется
в description.xml). Дальше: открыть в редакторе → расставить стрелки
(Topology) → «Сгенерировать путь» → стройка растягиванием (КС/платформы)
→ Ctrl+S → `collider-gen.exe <каталог маршрута>` для пешей физики.

## 8. Типовые проблемы

| Симптом | Причина/решение |
|---|---|
| Клавиши не работают | кликните в 3D-сцену; проверьте, что фокус не в текстовом поле GUI |
| Не двигается камера | держите ПКМ для вращения; WASD — только когда курсор в сцене |
| Не выбирается путь | вы не в режиме P, либо кликнули мимо линии — подсветки нет |
| Постройка «не тянется» | стройка работает только по выбранной траектории (сначала P+ЛКМ) |
| После Ctrl+S пропали объекты | объекты обвеса живут в track-edit.conf — он сохраняется вместе с маршрутом |

## 9. Перенесено из TSRE5 (обновление 2026-09-07)

### 9.1 Мини-карта (View → Карта)

Аналог MapWindow из TSRE: подложка OSM (схема) или спутник ArcGIS,
тайлы качаются в фоне и кэшируются на диск (`D:/rrs/caches/map_tiles`).

- Оранжевые линии — траектории; выделенная (P) — циановая;
- Синий маркер — камера;
- **ЛКМ по карте** — телепорт камеры в точку;
- **ПКМ/СКМ в окне карты** — зум +/−;
- Гео-привязка читается из `description.xml` маршрута (Latitude/
  Longitude; у маршрутов из osm-import — реальные координаты области).

### 9.2 Точное преобразование (окно Selected objects)

Аналог TransformWorldObjDialog: численный ввод позиции (м), поворота
(град) и масштаба; кнопки «Сбросить масштаб» и «На уровень земли».
Ввод применяется по Enter.

### 9.3 Импорт GPX-треков и высот SRTM (osm-import)

```
osm-import.exe --gpx трек.gpx --hgt папка_с_hgt --out D:
rs
outes\имя --name "Название"
```

- `--gpx` — треки/маршруты GPX становятся траекториями;
- `--hgt` — файл или каталог SRTM (N55E037.hgt): реальные высоты
  каждому пикету траекторий (уклоны как на местности); если в GPX
  есть `<ele>` — используются они;
- `--hgt` работает и с OSM-режимами (`--file/--bbox`).

### 9.4 Оптимизация

Выборка траектории кликом (P-режим) ускорена: сначала AABB-префильтр
по границам пути (8 углов бокса против луча), семплирование оси —
только для кандидатов рядом с лучом. На маршрутах с сотнями путей
клик перестаёт просчитывать всю сеть.

### Что было не так
1. **«Всё белое»** — пустая сцена без маршрута не заполняла кадр.
2. **Импортированные (OSM/GPX) маршруты не открывались** — диалог требовал
   папки models/ и textures/, которых у импортов нет.
3. **Точки нового пути (N) ставились только по 3D-объектам** — во «всем
   белом» кликать было некуда.

### Что сделано
- Вьюпорт: небесный фон + постоянная опорная сетка земли 10x10 км
  (шаг 100 м, каждые 500 м ярче) — видна и в пустом маршруте.
- Открытие маршрута: обязателен только каталог topology (models/
  textures/objects.ref можно докупить позже).
- Прокладка пути (N) как в TSRE:
  - клик в пустоту = точка на земле (луч ∩ плоскость z=0);
  - клик рядом с концом существующей траектории = ПРИЛИПАНИЕ к нему
    (продолжение пути, порог ~14 px);
  - от последней точки к курсору тянется живое превью сегмента
    (зелёная линия);
  - Backspace — убрать последнюю точку, Esc — выйти, окно «Новый путь»
    завершает (генерация траектории + ВСП).

## 11. Создание объектов и прокладка секциями (TSRE-style, 2026-09-07)

### 11.1 Установка объектов кликом (из списка)

1. **View → Model browser** — список моделей по категориям.
2. У нужной строки нажмите **«Кликом»** — включается режим установки
   (кнопка меняется на «Ставлю (Esc)»).
3. В сцене: зелёный маркер-круг с подписью модели и стрелкой поворота
   следует за курсором (снап к концам путей работает).
4. **ЛКМ** — поставить объект (можно серию, каждый клик — новый);
   **, / .** — поворот на 15° против/по часовой;
   **Esc** — выйти из режима.
Каждая установка попадает в undo (**Ctrl+Z**).

### 11.2 Прокладка пути секциями (N)

В окне «Новый путь» появился список **«Секция»**:

- первый клик ставит начало (по земле или с прилипанием к концу пути);
- дальше каждый клик пристыковывает выбранную секцию:
  - Прямая 25 / 50 / 100 / 200 м;
  - Кривая R300/R500/R800 на 10° / 25° / 45°;
- направление — ползунок «Направление» (0° = север); у дуг направление
  автоматически поворачивается на угол дуги (идём дальше по кривой);
- оранжевое превью секции рисуется от последней точки постоянно;
- «Свободный сплайн» — прежний режим произвольных точек;
- Backspace — убрать последний сегмент, окно «Создать путь» — финализация.
