## 2. Структура сценария. Простейшие функции

### 2.1. Простейший сценарий. Установка игрового времени и расположения поезда игрока

Любой сценарий пишется для конкретного маршрута в игре. Поэтому, естественным образом, все сценарии для конкретного маршрута должны располагаться в папке scenarios, расположенной в папке с маршрутом. Например, в состав игры входит маршрут "Испытательный полигон". Папка scenarios уже есть там

![Папка сценариев в стандартном маршруте "Испытательный полигон"](img/pic0001.PNG)


Если в том маршруте, для которого вы ведете разработку сценария, такой папки нет - создайте её!

В данной папке располагаются папки сценариев. Сценарий - это папка, содержащая файлы скриптов, файл описания, а в дальнейшем и звуковые файлы для озвучивания сценариев так же будут располагаться там.

Давайте создадим свой первый сценарий в RRS! Для примера будем использовать стандартный маршрут "Испытательный полигон".

Создадим в папке scenarios папку с именем сценария. Дадим ей имя hello_scenario

![Наш первый сценарий](img/pic0002.PNG)

**ВНИМАНИЕ!!!** Избегайте использования в именах папок и файлов сценариев национальных алфавитов и пробельных символов! Несмотря на то, что такие имена поддерживаются как ОС Windows, так и, по-видимому, движком Lua симулятора, не исключены проблемы при поиске и исполнении сценариев игрой! Только латиница, цифры, тире и подчеркивания.

Внутри этой папки создадим файл с именем main.lua


![Коневой скрипт сценария](img/pic0003.PNG)

**ВНИМАНИЕ!!!** Файл с именем main.lua обязан присутствовать в сценарии! Это так называемый корневой или стартовый скрипт, с которого начинается исполнение сценария. Игра ожидает наличие этого файла! Расширение *.lua так же является обязательным!

Теперь мы можем написать простейший сценарий. Начнем с того, что зададим время, с которого начнется игра при запуске сценария. Пишем в файле main.lua

```
setTime("17:30")
```

Обратите внимание на синтаксис - время мы указываем в кавычках, так как, с точки зрения игры, астрономическое время это строка. Игра сама преобразует строку в игровое время.

Далее, нам нужно задать поезд, которым мы будем играть. Сделаем это, написав такой код скрипта

```
my_train = TrainData.new()
my_train.name = "ВЛ60пк"
my_train.config = "vl60pk-1543"
my_train.traj = "track_a_p1a"
my_train.coord = 1690.0
my_train.dir = 1

setTrain(my_train)
```

Давайте разберем эти "заклинания". my_train - это структура, которая хранит информацию о поезде и его начальном положении. Вы можете дать ей любое имя, но со следующими ограничениями

* имя содержит ТОЛЬКО латиницу!
* имя не должно начинаться с цифры! Цифры далее - разрешены
* пробелы - не допускаются, тире - не допускаются. Используйте вместо них символ подчеркивания "_"

Первая строка
```
my_train = TrainData.new()
```

содает в памяти игры структуру описания вашего поезда. TrainData - стандартное имя этой структуры. new() - оператор, который её создает

Далее
```
my_train.name = "ВЛ60пк"
```

Здесь мы задаем имя нашего поезда. Это строка, поэтому она указана в кавычках! Это имя в дальнейшем используется для идентификации нашего поезда в различных операциях, выполняемых в сценариях.

**ВНИМАНИЕ!!!** Игра допускает здесь применение кириллических имен, как и в некоторых других случаях, которые мы оговорим позднее.


```
my_train.config = "vl60pk-1543"
```

Задаем имя конфига поезда. Эти конфиги лежат в игре в папке cfg/trains. Указанный конфиг - это электровоз ВЛ60пк резервом, вот он

![Конфиги поездов](img/pic0004.PNG)

В игру будет загружен поезд, описанный данным конфигом.

Идем дальше
```
my_train.traj = "track_a_p1a"
```

Указываем имя траектории, на которой стоит поезд. Что такое траектория в RRS? Это непрерывный участок пути, разделенный стрелками или изолированными стыками, имеющий собственное имя. В данном случае - это путь 1А на Станции А испытательного полигона. В карте это выглядит так

![Начальное положение поезда](img/pic0005.PNG)

Как узнать имя траектории? Ну, во-первых, если вы запустите игру в свободном режиме, без сценария, поставив любой поезд куда угодно, вы можете вывести в карте имена всех траекторий через меню "Вид -> Показать имена траекторий". И тогда вы увидете имя интересующей вас траектории, где-то в её середине. Вот так

![имя траектории](img/pic0006.PNG)

Но ползать по карте неудобно, искать имя долго. Есть другой способ получить имя интересующей траектории - выбрать ее наведя курсор и вызвать меню правой кнопкой

![имя траектории в буфер обмена](img/pic0007.PNG)

Имя нужной вам траектории будет скопировано в буфер обмена и в текст сценария вы его можете просто вставить (Ctrl + V / Shift + Insert)

Следующий параметр

```
my_train.coord = 1690.0
```
Координата головы поезда относительно начала траектории, в метрах. Этот параметр можно приблизительно оценить по карте. Другой способ, посмотреть конфиг topology/waypoints.conf раcположенный в папке с маршрутом. Обычно он включает некоторые траектории на станциях, которые можно использовать в качестве точек старта из лаунчера. Внутри этого файла

![путевая точка](img/pic0008.PNG)

перечислены так называемые "путевые точки". Каждая строка включает в себя строку с названием станции и именем пути или выходного светофора с этого пути, имя траектории, направление (1 - в данном случае), и координатой вдоль траектриии. Последний параметр

```
my_train.dir = 1
```

направление головы поезда. В cтарых терминах маршрутов ZDS 1 - "туда", -1 - "обратно". В терминах RRS - 1 - от начала траектории к концу, -1 - от конца траектории к началу.

Таким образом мы закончили описание поезда и следующей командой устанавливаем поезд в игру

```
setTrain(my_train)
```

Системная функция setTrain() принимает на вход структуру описания поезда.

### 2.2. Построение маршрута отправления. Понятие временно́го триггера

В реальности поезда отправляются по графику, в определенное графиком время. Дежурный по железнодорожной станции или поездной диспетчер *строят* маршрут отправления, переводя нужные стрелки и открывая сигналы.

Сценарии RRS позволяют задать такие действия по времени. Для этого предназначены так называемые *временны́е триггеры* - команда сценария, позволяющая задать произвольное действие, которое выполнится в заданное время. Команда выглядит так

```
setTimeTrigger("время срабатывания", имя_функции_действия)
```

В тексте нашего сценария напишем например так

```
setTimeTrigger("17:31", actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1))
```

Это означает, что в 17:31 по игровому времени будет построен поездной маршрут от траектории где находится наш поезд ("track_a_p1a"), до траектории на первом участке удаления от станции А, то есть до вот этой траектории, которая упирается в первый проходной светофор 22 на перегоне.

![](img/pic0013.PNG)

За построение маршрута отвечает отдельная функция

```
actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1)
```

Это стандартная action-функция, или "функция-действие", которая строит поездной маршрут от одной траектории до другой, в заданном направлении, а нашем случае в направлении "туда" (1).

Попробуем что у нас вышло. Перезапускаем игру с нашим сценарием. Ровно в 17:31 открывается маршрутный сигнал ЧМ1 и на карте отображается построенный маршрут отправления

![](img/pic0014.PNG)

![](img/pic0015.PNG)

Можно отправляться!

Временной триггер можно задать иначе - установить время относительно времени страрта игры. Сделать это можно, указав "+" перед значением времени

```
setTimeTrigger("+00:01", actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1))
```

Это означает, что маршрут будет построен через 1 минуту после начала игры. Вы можете проэкспериментировать, указав теперь произвольное время в setTime. Маршрут будет построен ровно через минуту от указанного вами времени начала игры.

Для большинства типовых действий игрой предусмотрены стандартные action-функции, полный список которых приведен в [Приложении 2](appendix2.md).

Такми образом, вот полный текст нашего первого сценария для RRS.

```
setTime("17:30")

my_train = TrainData.new()
my_train.name = "ВЛ60пк"
my_train.config = "vl60pk-1543"
my_train.traj = "track_a_p1a"
my_train.coord = 1690.0
my_train.dir = 1

setTrain(my_train)

setTimeTrigger("17:31", actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1))
```

Соласитесь, выглядит как книга заклинаний. Чтобы сделать этот текст более понятным, как для себя, так и для других, можно использовать комментарии. Ведь Lua - полноценный язык программирования, и допускает использования комментариев.

В Lua есть два вида комментариев: однострочные и многострочные. Однострочный комментарий начинается с двух идущих подряд тире "--". Например,

```
-- Задаем время начала игры
setTime("17:30")

-- Описываем поезд игрока
my_train = TrainData.new()
my_train.name = "ВЛ60пк"
my_train.config = "vl60pk-1543"
my_train.traj = "track_a_p1a"
my_train.coord = 1690.0
my_train.dir = 1

-- Устанавливаем поезд игрока
setTrain(my_train)

-- Строим маршрут отправления в 17:31 с пути 1А станции А
setTimeTrigger("17:31", actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1))
```

Многострочный комментарий начинается с последовательности символов "--[[" и оканчивается последовательностью "]]", например

```
--[[

Мой первый сценарий
для Russian Railway Simulator

]]

-- Задаем время начала игры
setTime("17:30")

-- Описываем поезд игрока
my_train = TrainData.new()
my_train.name = "ВЛ60пк"
my_train.config = "vl60pk-1543"
my_train.traj = "track_a_p1a"
my_train.coord = 1690.0
my_train.dir = 1

-- Устанавливаем поезд игрока
setTrain(my_train)

-- Строим маршрут отправления в 17:31 с пути 1А станции А
setTimeTrigger("17:31", actionBuildTrainRoute("track_a_p1a", "track_a-b_nd-22", 1))
```

Крайне рекомендуем использовать комментарии! Это поможет и вам разобраться в том, что вы написали, и другим сценаристам вникнуть в суть происходящего в вашем сценарии. Кроме того, комментарии могут использоваться для того, чтобы сделать неактивной команду или несколько команд сценария, превратив их временно в комментарии (например при отладке, если что-то пошло не так).

### 2.5. Сценарий, как дополнение к игре. Структура папок

Мы написали простейший сценарий, и продолжим изучение системы сценариев RRS в дальнейшем. Однако, раз речь в данной главе зашла о структуре сценария, то следует сказать, что сценарий - такое же дополнение симулятора, как подвижной состав или маршрут. Потому, грамотно разработанный сценарий должен соответствовать структуре дополнения для RRS.

Вспомним структуру каталогов игры

![](img/pic0026.PNG)

Маршруты располагаются в каталоге routes. Значит, ваш сценарий, в готовом для распространения виде, например для маршрута "Испытательный полигон", должен повторять данную структуру каталогов

```
my_scenario/-
            |-routes/-
                     |-experimental-polygon_v2.0/-
                                                 |-sсenarios-
                                                            |-my_scenario1
                                                            |-my_scenario2
```

Таким образом, ваш проект сценариев для данного маршрута может содержать несколько папок с разными сценариями.


Например, вам может понадобиться использовать сценарии, которые используют конфигурации поездов, которых нет у игрока. Вы можете заранее сформировать эти поезда, написав их конфиги и положить в комплект сценария, разместив папке cfg/trains, например

```
my_scenario/-
            |-cfg/-
                  |-trains/-
                           |-train104.xml
                           |-train105.xml
            |-routes/-
                     |-experimental-polygon_v2.0/-
                                                 |-sсenarios-
                                                            |-my_scenario1
                                                            |-my_scenario2
```


Здесь train104.xml и train105.xml - конфиги поездов, которые вы составили сами и используете в сценарии.

Можно пойти дальше, например, ваш поезд train104.xml использует нестандартный конфиг для электровоза ВЛ60пк, которого нет в игре. Вы можете, учтя структуру каталогов игры поставить такой конфиг вместе со сценарием. Не буду подробно описывать это здесь, но такая возможность существует и её реализация требует более глубокого понимания структуры игры, которое можно почерпнуть из изучения документации на сайте https://rusrailsim.ru
