## Приложение 1. Перечень системных функций


|Функция     | Параметры    | Описание    |
|------------|--------------|-------------|
| setTime |  "hh:mm:ss" | Установить вермя начала игры (допускается опустить секунды) |
| setDate |   "dd.mm.yyyy" | Установить дату начала игры |
| setDateTime| "dd.mm.yyyy  hh:mm:ss" | Установить дату и время начала игры (допускается опустить секунды)|
|setTrain|Структура TrainData (см. [приложение 4](appendix4.md)) c параметрами: name - имя поезда, config - имя файла с конфигом поезда, traj - траектория, где находится голова поезда, coord - координата головы поезда вдоль траектории, dir - направление (1 - туда, -1 - обратно)|Установить поезд в заданное положение|
|switchFwd|"имя стрелки"|Переключить стрелку спереди|
|switchBwd|"имя стрелки"|Переключить стрелку сзади|
|delay|величина задержки, сек.| Задержка выполнения очереди команд|
|buildTrainRoute|"начальная траектория", "конечная траектория", направление (1 - туда, -1 - обратно)|Построить поездной маршрут. Происходит автоматический перевод стрелок и открытие всех попутных поездных сигналов|
|buildShuntingRoute|"начальная траектория", "конечная траектория", направление (1 - туда, -1 - обратно)|Построить маневровый маршрут. Происходит автоматический перевод стрелок и открытие всех попутных маневровых сигналов|
|setSwitchsAlongRoute|"начальная траектория", "конечная траектория", направление (1 - туда, -1 - обратно)|Установить стрелки по маршруту|
|setTrigger|функция обработки события вида trig_func(train_name, traj_name, is_busy)|Установка триггера, срабатывающего при занятии или освобождении какой либо траектории. Происходит вызов функции trig_func (имя может быть произвольным) с передачей туда имени поезда (train_name)б имени траектории, изменившей состояние (traj_name) и повое состояние занятости (is_busy)|
|setTimeTrigger|"hh:mm:ss" (или "+hh:mm:ss"), имя исполняемой функции trig_func|Установка исполнения произвольной функции trig_func в заданый момент времени. Время может быть абсолютным ("hh:mm::ss)" или задано относительно времени старта игры ("+hh:mm:ss"). Допускается не указывать секунды|
|setPostEventTimeTrigger|"+hh:mm:ss",функция для исполнения trig_func|Устанавливает триггер, срабатывающий через указанный променуток времени с момента установки данного триггере. При срабатывании устанавливается заданная функция trig_func|
|openShuntingSignal|"имя коннетора", направление сигнала (1 - туда, -1 - обратно|Открыть маршрутный сигнал, установленный на коннекторе с заданным именем в заданном направлении|
|openCallSignal|"имя коннетора", направление сигнала (1 - туда, -1 - обратно|Открыть пригласительный сигнал, установленный на коннекторе с заданным именем в заданном направлении|
|getTrajState|"имя траектории"|Получить состояние траектории с данным именем. Возвращает два параметра (см. [приложение 4](appendix4.md)): is_busy - занятость (true/false), in_route - включенность в уже построенный маршрут (true/false)|
|logMessage|"текст сообщения"|Вывести произвольный текст в logs/journal.log|
|getNextTraj|"имя траектории", направление (1 - туда, -1 - обратно)|Получить имя траектории, следующей за указанной траекторией, в заданном направлении|
