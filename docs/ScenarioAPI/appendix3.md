## Приложение 3. Стандартные позиционные триггеры


|Функция|Параметры|Назначение|
|-|-|-|
|setOnTrajBusyTrigger|"имя траектории", выполняемая функция (action)|Выполнение заданной action-функции при занятии указанной траектории. Срабатывает однократно.|
|setOnTrajFreeTrigger|"имя траектории", выполняемая функция (action)|Выполнение заданной action-функции при освобождении указанной траектории. Срабатывает однократно.|
|setOnTrajBusyByTrainTrigger|"имя траектории", "имя поезда", выполняемая функция (action)|Выполнение заданной action-функции при занятии указанной траектории поездом с указанным именем. Срабатывает однократно.|
|setOnTrajFreeByTrainTrigger|"имя траектории", "имя поезда", выполняемая функция (action)|Выполнение заданной action-функции при освобождении указанной траектории поездом с указанным именем. Срабатывает однократно.|
|setAutoApproachTrigger|"имя начальной траектории", "имя конечной траектории", направление (1 - туда, -1 - обратно)|Автоматически строит маршрут в заданном направлении между начальной и конечной траекториями, по факту занятия начальной траектории любым поездом. Существует в течение всей игры с момента своей установки. При построении маршрута учитывается занятость возможных промежуточных траекторий и стрелок. Может использоваться для автоматического пропуска поездов по станции в заданном направлении.|

**Примечание**: в качестве action-функции для перечисленных триггеров может быть использована ЛЮБАЯ из action-функций, описанных в [приложении 2](appendix2.md), а так же любая функция, созданная разработчиком сценария. В качестве action-функции НЕ МОЖЕТ быть использована системная функция (cм. [приложение 1](appendix1.md)), однако данное ограничение можно обойти, написав для нужной функции Lua-обертку.
