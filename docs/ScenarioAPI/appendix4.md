## Приложение 4. Стандартные структуры данных сценариев

**TrainData** - структура описания поезда

| Имя поля | Назначение | Тип данных |
|-|-|-|
|name|имя поезда|строка|
|config|имя файла конфига поезда|строка|
|traj|имя траектории, на которой расположен поезд|строка|
|coord|координата поезда на траектории|число от 0 до длины траектории, м|
|dir|направление головы поезда|Целое число: 1 - к конечной точке траектории, -1 - к начальной точке траектории|
|auto|включение автоматического управления движением поезда|Логический: true - включено, false - выключено. Выключено по-умолчанию, можно не указывать для поездов, управляемых вручную|

Пример использования

```
-- Устанавливаем поезд 102

-- Создаем структуру в памяти игры
train102 = TrainData.new()

-- Задаем параметры
train102.name = "102"
train102.config = "vl60pk-1543-T65_17"
train102.traj = "track_b_p4"
train102.coord = 1250.0
train102.dir = 1 
train102.auto = true

-- Устанавливаем поезд в игре
setTrain(train102)
```

**TrajState** - структура состояния траектории

|Имя поля|Назначение|Тип данных|
|-|-|-|
|is_busy|занятость траектории подвижным составом|true - занята, false - свободна|
|in_route|признак включения траектории в поездной или маневровый маршрут|true - траектория включена в маршрут, false - траектория не входит ни в какой маршрут|

Пример использования

```
-- Запрос состояния траектории "track_a_p1a"
local traj_state = getTrajState("track_a_p1a")

-- Проверяем занятость траектории
if traj_state.is_busy then

	-- Действия, которые мы предпримем, если траектория занята

end

-- Проверяем включение траектории в маршрут
if traj_state.in_route then

	-- Действия, котоые мы предпримем, если траектория включена в маршрут

end
```
