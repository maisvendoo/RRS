# Реестр изменений заголовков SDK

`sdk/` в дистрибутиве — публичный API для разработчиков аддонов ПС.
Состав (RRS_SDK_COMPONENTS, корневой CMakeLists.txt):
core, filesystem, Journal, physics, solver, CfgReader, device,
display, io-controller, vehicle. Их заголовки ставятся правилами
`install(... FILE_SET HEADERS DESTINATION sdk/include)`.

**Правило (2026-09-09): любое изменение заголовков этого состава —
предмет обсуждения и сопровождается записью в этот реестр
с обоснованием. Изменение без записи не делается.**

Базовая линия сравнения: апстрим maisvendoo/RRS, ветка
v1.10.0-devel (a38e857).

## Текущие отличия от апстрима

### simulator/vehicle/include/vehicle.h

| № | Изменение | Автор | Обоснование | Статус |
|---|-----------|-------|-------------|--------|
| 1 | +461 строк: подсистемные геттеры/сеттеры (getEnergy, getPantograph, getDamageSystem, getDepotPower, setCatenaryFeed, система сцепления и пр.) | команда | Основа всей текущей сборки: модель/клиент/аддоны работают через этот API | Командное решение, лежит в базе |
| 2 | Удалены `DieselEngineSystem& getDiesel()` и член `diesel` | сессия 2026-09-09 | Дизеля нет ни в одной ПЕ (по указанию владельца форка). **Ломающее изменение SDK** — внешние аддоны тепловозов не соберутся | **К обсуждению**: подтвердить удаление или вернуть как пустой API |
| 3 | Добавлен `#include <catenary-system.h>` | сессия 2026-09-09 | Фикс компиляции: заголовок использует `catenary::FeedState` в сигнатуре setCatenaryFeed, но не включает определение типа (MSVC прощал, MinGW — нет) | Кандидат в PR апстриму |

## Отклонённые изменения (не входят, зафиксировано)

- Источники кассеты (setBrakeSources/setBrakeERSource/
  setTractionCurrentSource) в Vehicle — замечание maisvendoo,
  перенесено в VehicleTelemetry (п.6).
- Hanging brake (setHangingBrake) в Vehicle — перенесено в модель
  (инжект ЭТ через штатный control_signals / CS_BRAKE_CRANE).
- Паровоз SteamEngineSystem — удалён вместе с дизелем (нет ПС).
