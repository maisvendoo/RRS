# AGENTS.md — инструкции для ИИ-ассистента (opencode)

## Общие правила

- Всегда ждать утверждения плана перед началом работы. Ничего не делать без команды.
- КАТЕГОРИЧЕСКИ любые правки файлов проекта делать только спросив разрешения.
- Каждая реализованная функция ДОЛЖНА сопровождаться коммитом и отправкой изменений в удаленный репозиторий.
- Комментарии к коммитам — только на русском языке.
- Комментарии в коде — только на русском языке.
- Не добавлять то, что не просили. Не выдумывать лишнего.
- Действовать строго в рамках описания поставленной задачи.

## Правила планирования задачи

Задача разбивается на этапы - слайсы. Каждый слайс привносящий новый функционал, не ломает работоспособность проекта, но приближает в целом конечную цель. Обязательны коммит и пуш после каждого слайса. При планировании выводить побробный список слайсов с описанием их изменений. Не выполнять план, не получив подтверждение, разрешающее работать с кодом и файлами проекта.

КАТЕГОРИЧЕСКОЕ ТРЕБОВАНИЕ: При планировании учитывать изменения инрефейсов классов, входящих в SDK (библиотеки и заголовочные файлы, устанавливаниемы командой make install или mingw32-make install). Отдельно выделять при предоставлении плана эти места, с подробным обоснованием причин изменения. НЕ ПРАВИТЬ SDK без резрешения.

КАТЕГОРИЧЕСКИ ЗАПРЕШЕНО слияние веток без явного на то указания!
