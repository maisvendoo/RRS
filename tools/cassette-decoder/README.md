# Расшифровка кассет регистрации RRS (.kr)

Программа расшифровки для ТЧМИ (ТЗ «Кассеты регистрации», промт 2).
Отдельная веб-страница: откройте `index.html` в браузере (или разместите
на сайте как вкладку ТЧМИ) — зависимостей нет, всё локально.

## Использование
1. Файл → выбрать `.kr` (создаётся симулятором в `Cassettes/`,
   извлечение — `Ctrl+R` в игре).
2. Программа проверяет целостность: MagicBytes, CRC32 заголовка и всех
   блоков, мастер-хеш SHA-256, отпечаток ключа сессии, подпись, футер
   (незавершённая запись помечается — данные до последнего сброса).
3. Отображает: график скорости с допустимой и зонами превышения,
   давления (ТМ/УР/ТЦ/НМ — УР синей линией, коррелирует с ТМ),
   ток/напряжение, дискретные состояния
   (ЭПК/тяга/рекуперация/песок/экстренное), профиль пути (уклон + км/пк/м),
   лог нажатий (фильтр, клик по строке — курсор к моменту), протокол
   нарушений (превышения скорости, клик — к моменту), статус-бар.
   Клик по любому графику — синхронный курсор.
4. Экспорт CSV — все каналы по временной сетке.

## Формат (соответствует simulator/cassette)
```
заголовок  : magic "RRS-KR-CASSETTE\0" (16) + версия u16 + флаг u8 + CRC32
блок 0     : ОТКРЫТЫЙ серийник кассеты (из него выводится ключ сессии)
блоки      : [id u32][len u32][шифр AES-256-CBC][CRC32(id+len+шифр)]
ключ       : sha256(мастер-ключ ‖ серийник)  — в файле НЕ хранится
IV блока   : sha256(серийник ‖ смещение блока u64le)[0..16]
блок 1     : метаданные (серийник, локо, масса, описатели каналов)
блоки 5-8  : чанки: аналоговые (дельта 0.01 + zigzag-varint),
             дискретные события, лог нажатий, профиль пути
блок 9     : мастер-хеш SHA-256 + отпечаток ключа + подпись
футер      : "KR-END\0\0" + CRC32 всего файла
```
Ключи/подписи вводятся/проверяются через WebCrypto (AES-CBC, SHA-256).

## Верификация
`_verify/verify_kr_roundtrip.py` — сквозной тест писатель→читатель
(зеркала C++ и JS-логики) с настоящим AES: 15 проверок, включая
обрезанный файл и подделку байта.
